常见问题

这是一款什么应用？

家庭法庭让一家人在家玩有趣的角色扮演式模拟法庭，让孩子自然而然地理解法律、公平与规则的意义。遇到不公平的事就提起民事诉讼，家规被打破就提起刑事诉讼，再分配好法官和辩护人的角色，开庭审理。

多大的孩子可以玩？

会读字的孩子都可以和家长一起玩。有庭审台词和提示，更小的孩子在大人的帮助下也能参与。

需要联网吗？

不需要。庭审、记录和其他所有功能都可以离线使用。只有在设置里用“发送反馈”向开发者发送反馈时，才需要联网并登录 iCloud。

我的数据保存在哪里？

你的家人、法典、庭审和判决只保存在设备上的 familycourt.json 文件中，不会发送到任何外部服务器。详情请见隐私政策。

可以备份记录或迁移到另一台设备吗？
  • 在首页或设置中使用保存记录，即可把数据导出为文件。
  • 在另一台设备上选择设置 → 导入记录并打开该文件，即可恢复全部内容。
  • 从旧版网页版导出的备份文件也可以导入。
我用免费 Apple ID 安装了应用，却打不开。

用免费 Apple ID 安装的应用，每 7 天需要重新运行（重新安装）一次。重新安装时数据会保留，但建议先用保存记录备份。使用付费开发者账号（99 美元/年）的话，应用可有效使用一年。

怎样安装到 iPad 上？
  • 在 Mac 上用 Xcode 打开 FamilyCourt.xcodeproj。
  • 在 Signing & Capabilities 中选择你自己的 Apple ID（Team）。
  • 连接 iPad，点按 ▶ Run 即可安装。
  • 完整步骤请见 GitHub 上的 README。
怎样彻底删除我的数据？

删除应用会清除保存在设备上的所有数据。家人和庭审记录从不离开设备，所以其他地方不会留有任何内容。如果想删除你用“发送反馈”发送的反馈，请发邮件至 leeo@kakao.com。
