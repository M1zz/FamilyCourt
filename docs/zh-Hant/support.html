常見問題

這是一款什麼 App？

家庭法庭讓一家人在家玩有趣的角色扮演式模擬法庭，讓孩子自然而然地理解法律、公平與規則的意義。遇到不公平的事就提起民事訴訟，家規被打破就提起刑事訴訟，再分配好法官和辯護人的角色，開庭審理。

幾歲的孩子可以玩？

會讀字的孩子都可以和家長一起玩。有庭審台詞和提示，更小的孩子在大人的協助下也能參與。

需要連上網路嗎？

不需要。庭審、紀錄和其他所有功能都可以離線使用。只有在設定中用「傳送意見回饋」向開發者傳送意見時，才需要連上網路並登入 iCloud。

我的資料儲存在哪裡？

你的家人、法典、庭審和判決只儲存在裝置上的 familycourt.json 檔案中，不會傳送到任何外部伺服器。詳情請見隱私權政策。

可以備份紀錄或轉移到另一台裝置嗎？
  • 在首頁或設定中使用儲存紀錄，即可把資料匯出成檔案。
  • 在另一台裝置上選擇設定 → 匯入紀錄並開啟該檔案，即可還原全部內容。
  • 從舊版網頁版匯出的備份檔也可以匯入。
我用免費的 Apple ID 安裝了 App，卻打不開。

用免費 Apple ID 安裝的 App，每 7 天需要重新執行（重新安裝）一次。重新安裝時資料會保留，但建議先用儲存紀錄備份。使用付費的開發者帳號（每年 99 美元）的話，App 可有效使用一年。

要怎麼安裝到 iPad 上？
  • 在 Mac 上用 Xcode 開啟 FamilyCourt.xcodeproj。
  • 在 Signing & Capabilities 中選擇你自己的 Apple ID（Team）。
  • 連接 iPad，按下 ▶ Run 即可安裝。
  • 完整步驟請見 GitHub 上的 README。
要怎麼徹底刪除我的資料？

刪除 App 會清除儲存在裝置上的所有資料。家人和庭審紀錄從不離開裝置，所以其他地方不會留有任何內容。如果想刪除你用「傳送意見回饋」傳送的意見，請寄信至 leeo@kakao.com。
