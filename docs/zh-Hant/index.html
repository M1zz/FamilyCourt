這是一款什麼 App？

😤

覺得不公平的時候

孩子可以當原告提出起訴狀。這是一場把委屈說出口的民事訴訟。

🚨

家規被打破的時候

家規被打破時，由檢察官提起訴訟。法官可以判決有罪、無罪或從輕處理。

🧑‍⚖️

人人角色公平

只有不是原告或被告的人才能當法官。每個人都有權選擇辯護人。

📖

我們家的法典

全家一起制定家規，再把每個案件從開庭、判決一路追蹤到履行承諾。

玩法

  1. 全家一起商量好家規，寫進法典。
  2. 遇到不公平的事提起民事訴訟，家規被打破則提起刑事訴訟。
  3. 選好原告、被告、法官和辯護人的角色，宣布開庭。
  4. 聽完各方陳述，由法官作出判決。
  5. 根據判決訂下一個承諾，做到了就打勾。
🔒

孩子用得放心

不用註冊，沒有廣告，也沒有追蹤。你的家人、法典和庭審紀錄只儲存在你的裝置上，不會傳送到任何地方。開發者只會收到你在設定中主動傳送的意見回饋，以及無法識別個人身分的匿名使用統計。詳情請見隱私權政策。
