Συχνές ερωτήσεις

Τι είναι αυτή η εφαρμογή;

Το Οικογενειακό Δικαστήριο επιτρέπει στις οικογένειες να διοργανώνουν στο σπίτι παιχνιδιάρικες δίκες ρόλων, ώστε τα παιδιά να καταλαβαίνουν φυσικά τι σημαίνουν ο νόμος, η δικαιοσύνη και οι κανόνες. Καταθέστε κάτι άδικο ως αστική υπόθεση ή έναν παραβιασμένο κανόνα του σπιτιού ως ποινική υπόθεση, μοιράστε τους ρόλους του δικαστή και του συνηγόρου και κάντε τη δίκη.

Τι ηλικία χρειάζεται;

Κάθε παιδί που ξέρει να διαβάζει μπορεί να παίξει με έναν γονέα. Το σενάριο της δίκης και η καθοδήγηση επιτρέπουν να συμμετέχουν και μικρότερα παιδιά με τη βοήθεια ενός ενηλίκου.

Χρειάζομαι σύνδεση στο διαδίκτυο;

Όχι. Οι δίκες, τα αρχεία και όλα τα υπόλοιπα λειτουργούν εκτός σύνδεσης. Χρειάζεστε διαδίκτυο και σύνδεση στο iCloud μόνο όταν στέλνετε σχόλια στον προγραμματιστή με την Αποστολή σχολίων στις Ρυθμίσεις.

Πού αποθηκεύονται τα δεδομένα μου;

Τα μέλη της οικογένειας, ο κώδικας, οι δίκες και οι αποφάσεις αποθηκεύονται μόνο σε ένα αρχείο familycourt.json στη συσκευή σας. Τίποτα δεν στέλνεται σε εξωτερικό διακομιστή. Δείτε την Πολιτική απορρήτου για λεπτομέρειες.

Μπορώ να κάνω αντίγραφο ασφαλείας των αρχείων ή να τα μεταφέρω σε άλλη συσκευή;
  • Χρησιμοποιήστε την Αποθήκευση αρχείων στην αρχική οθόνη ή στις Ρυθμίσεις για να εξαγάγετε τα δεδομένα σας σε αρχείο.
  • Σε άλλη συσκευή, επιλέξτε Ρυθμίσεις → Εισαγωγή αρχείων και ανοίξτε αυτό το αρχείο για να επαναφέρετε τα πάντα.
  • Μπορείτε επίσης να εισαγάγετε αρχεία αντιγράφου που εξήχθησαν από την παλαιότερη έκδοση ιστού.
Εγκατέστησα την εφαρμογή με δωρεάν Apple ID και δεν ανοίγει.

Οι εφαρμογές που εγκαθίστανται με δωρεάν Apple ID πρέπει να εκτελούνται ξανά (επανεγκατάσταση) κάθε 7 ημέρες. Τα δεδομένα σας διατηρούνται κατά την επανεγκατάσταση, αλλά συνιστούμε να κάνετε πρώτα αντίγραφο με την Αποθήκευση αρχείων. Με έναν επί πληρωμή λογαριασμό προγραμματιστή (99 $ τον χρόνο) η εφαρμογή ισχύει για ένα χρόνο.

Πώς την εγκαθιστώ σε iPad;
  • Σε Mac, ανοίξτε το FamilyCourt.xcodeproj στο Xcode.
  • Στο Signing & Capabilities επιλέξτε το δικό σας Apple ID (Team).
  • Συνδέστε το iPad και πατήστε ▶ Run για εγκατάσταση.
  • Για όλα τα βήματα, δείτε το README στο GitHub.
Πώς διαγράφω εντελώς τα δεδομένα μου;

Η διαγραφή της εφαρμογής αφαιρεί όλα τα δεδομένα που είναι αποθηκευμένα στη συσκευή σας. Τα δεδομένα της οικογένειας και των δικών δεν φεύγουν ποτέ από τη συσκευή, οπότε δεν μένει τίποτα αλλού. Αν θέλετε να διαγραφούν σχόλια που στείλατε με την Αποστολή σχολίων, στείλτε email στο leeo@kakao.com.
