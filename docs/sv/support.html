Vanliga frågor

Vad är det här för app?

Med Familjerätten kan familjer hålla lekfulla rollspelsrättegångar hemma, så att barn helt naturligt lär sig vad lag, rättvisa och regler betyder. Lämna in något orättvist som tvistemål eller en bruten husregel som brottmål, fördela rollerna som domare och försvarare och håll förhandlingen.

Hur gammal måste man vara?

Alla barn som kan läsa kan spela med en förälder. Med rättegångsmanuset och vägledningen kan även yngre barn vara med med en vuxens hjälp.

Behöver jag internetanslutning?

Nej. Rättegångar, uppgifter och allt annat fungerar offline. Du behöver bara internet och iCloud-inloggning när du skickar feedback till utvecklaren med Skicka feedback i Inställningar.

Var lagras mina data?

Dina familjemedlemmar, lagbok, rättegångar och domar sparas bara i en familycourt.json-fil på din enhet. Inget skickas till någon extern server. Se integritetspolicyn för mer information.

Kan jag säkerhetskopiera mina uppgifter eller flytta dem till en annan enhet?
  • Använd Spara uppgifter på hemskärmen eller i Inställningar för att exportera dina data till en fil.
  • Välj Inställningar → Importera uppgifter på en annan enhet och öppna filen för att återställa allt.
  • Säkerhetskopior som exporterats från den äldre webbversionen kan också importeras.
Jag installerade appen med ett gratis Apple-ID och den går inte att öppna.

Appar som installerats med ett gratis Apple-ID måste köras (installeras om) var 7:e dag. Dina data finns kvar när du installerar om, men vi rekommenderar att du först säkerhetskopierar med Spara uppgifter. Med ett betalt utvecklarkonto (99 USD per år) gäller appen i ett år.

Hur installerar jag den på en iPad?
  • Öppna FamilyCourt.xcodeproj i Xcode på en Mac.
  • Välj ditt eget Apple-ID (Team) under Signing & Capabilities.
  • Anslut iPaden och tryck på ▶ Run för att installera.
  • Alla steg finns i README på GitHub.
Hur raderar jag mina data helt?

Om du raderar appen tas alla data på din enhet bort. Familje- och rättegångsdata lämnar aldrig enheten, så inget finns kvar någon annanstans. Om du vill att feedback som skickats med Skicka feedback ska raderas, mejla leeo@kakao.com.
