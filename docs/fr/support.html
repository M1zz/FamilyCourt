Questions fréquentes

De quoi s’agit-il ?

Tribunal Familial permet aux familles d’organiser à la maison des procès ludiques en jeu de rôle, pour que les enfants comprennent naturellement ce que sont la loi, l’équité et les règles. Déposez une injustice comme affaire civile, ou une règle de la maison brisée comme affaire pénale, puis répartissez les rôles de juge et d’avocat et tenez le procès.

Quel âge faut-il avoir ?

Tout enfant qui sait lire peut jouer avec un parent. Grâce au texte du procès et aux consignes, même les plus jeunes peuvent participer avec l’aide d’un adulte.

Faut-il une connexion Internet ?

Non. Les procès, les enregistrements et tout le reste fonctionnent hors ligne. Vous n’avez besoin d’Internet et d’une connexion à iCloud que pour envoyer un retour au développeur avec Envoyer un retour dans les Réglages.

Où sont enregistrées mes données ?

Les membres de votre famille, le code, les procès et les verdicts sont enregistrés uniquement dans un fichier familycourt.json sur votre appareil. Rien n’est envoyé à un serveur externe. Consultez la Politique de confidentialité pour en savoir plus.

Puis-je sauvegarder mes données ou les transférer sur un autre appareil ?
  • Utilisez Enregistrer les données sur l’écran d’accueil ou dans les Réglages pour exporter vos données dans un fichier.
  • Sur un autre appareil, choisissez Réglages → Importer les données et ouvrez ce fichier pour tout restaurer.
  • Les fichiers de sauvegarde exportés depuis l’ancienne version web peuvent aussi être importés.
J’ai installé l’app avec un identifiant Apple gratuit et elle ne s’ouvre plus.

Les apps installées avec un identifiant Apple gratuit doivent être relancées (réinstallées) tous les 7 jours. Vos données sont conservées à la réinstallation, mais nous vous conseillons de sauvegarder d’abord avec Enregistrer les données. Avec un compte développeur payant (99 $ par an), l’app reste valide un an.

Comment l’installer sur un iPad ?
  • Sur un Mac, ouvrez FamilyCourt.xcodeproj dans Xcode.
  • Dans Signing & Capabilities, choisissez votre propre identifiant Apple (Team).
  • Branchez l’iPad et appuyez sur ▶ Run pour installer.
  • Pour toutes les étapes, consultez le README sur GitHub.
Comment supprimer complètement mes données ?

Supprimer l’app efface toutes les données enregistrées sur votre appareil. Les données de la famille et des procès ne quittent jamais l’appareil, donc il n’en reste rien ailleurs. Si vous voulez faire supprimer un retour envoyé avec Envoyer un retour, écrivez à leeo@kakao.com.
