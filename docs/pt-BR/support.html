Perguntas frequentes

O que é este app?

O Tribunal da Família permite que as famílias façam julgamentos divertidos de faz de conta em casa, para que as crianças entendam naturalmente o que são lei, justiça e regras. Registre algo injusto como caso civil, ou uma regra da casa quebrada como caso penal, depois distribua os papéis de juiz e defensor e faça o julgamento.

Qual a idade mínima?

Qualquer criança que saiba ler pode jogar com um adulto. O roteiro do julgamento e as orientações permitem que até as menores participem com a ajuda de um adulto.

Preciso de conexão com a internet?

Não. Julgamentos, registros e todo o resto funcionam offline. Você só precisa de internet e de login no iCloud ao enviar feedback ao desenvolvedor com Enviar feedback, nos Ajustes.

Onde meus dados ficam guardados?

Os membros da família, o livro de leis, os julgamentos e os vereditos ficam guardados apenas em um arquivo familycourt.json no seu dispositivo. Nada é enviado a um servidor externo. Veja a Política de Privacidade para saber mais.

Posso fazer backup dos registros ou levá-los para outro dispositivo?
  • Use Salvar registros na tela Início ou nos Ajustes para exportar seus dados para um arquivo.
  • Em outro dispositivo, escolha Ajustes → Importar registros e abra esse arquivo para restaurar tudo.
  • Arquivos de backup exportados da versão web antiga também podem ser importados.
Instalei o app com um ID Apple gratuito e ele não abre.

Apps instalados com um ID Apple gratuito precisam ser executados (reinstalados) de novo a cada 7 dias. Seus dados são mantidos ao reinstalar, mas recomendamos fazer um backup antes com Salvar registros. Com uma conta de desenvolvedor paga (US$ 99 por ano), o app continua válido por um ano.

Como instalo no iPad?
  • Em um Mac, abra o FamilyCourt.xcodeproj no Xcode.
  • Em Signing & Capabilities, escolha o seu próprio ID Apple (Team).
  • Conecte o iPad e toque em ▶ Run para instalar.
  • Para ver todos os passos, consulte o README no GitHub.
Como apago meus dados por completo?

Apagar o app remove todos os dados guardados no seu dispositivo. Os registros da família e dos julgamentos nunca saem do dispositivo, então não sobra nada em outro lugar. Se quiser apagar um feedback enviado com Enviar feedback, escreva para leeo@kakao.com.
