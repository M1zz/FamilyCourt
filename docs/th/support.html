คำถามที่พบบ่อย

แอปนี้คืออะไร

ศาลครอบครัวให้ครอบครัวจัดการพิจารณาคดีสนุก ๆ แบบเล่นบทบาทสมมติที่บ้าน เด็ก ๆ จึงเข้าใจความหมายของกฎหมาย ความยุติธรรม และกฎเกณฑ์ได้อย่างเป็นธรรมชาติ ยื่นเรื่องไม่ยุติธรรมเป็นคดีแพ่ง หรือกฎของบ้านที่ถูกละเมิดเป็นคดีอาญา แล้วแบ่งบทบาทผู้พิพากษาและทนายความ จากนั้นเปิดการพิจารณา

ต้องอายุเท่าไรถึงจะเล่นได้

เด็กที่อ่านออกก็เล่นกับผู้ปกครองได้ มีบทพูดและคำแนะนำในการพิจารณา เด็กเล็กกว่านั้นก็ร่วมได้ด้วยความช่วยเหลือของผู้ใหญ่

ต้องเชื่อมต่ออินเทอร์เน็ตไหม

ไม่ต้อง การพิจารณาคดี บันทึก และทุกอย่างใช้งานแบบออฟไลน์ได้ ต้องใช้อินเทอร์เน็ตและลงชื่อเข้าใช้ iCloud เฉพาะเมื่อส่งความคิดเห็นถึงผู้พัฒนาด้วยส่งความคิดเห็นในการตั้งค่า

ข้อมูลของฉันเก็บไว้ที่ไหน

สมาชิกครอบครัว ประมวลกฎหมาย การพิจารณาคดี และคำตัดสินจะบันทึกไว้เฉพาะในไฟล์ familycourt.json บนอุปกรณ์ของคุณ ไม่มีการส่งไปยังเซิร์ฟเวอร์ภายนอก ดูรายละเอียดในนโยบายความเป็นส่วนตัว

สำรองบันทึกหรือย้ายไปอุปกรณ์เครื่องอื่นได้ไหม
  • ใช้บันทึกข้อมูลที่หน้าหลักหรือในการตั้งค่าเพื่อส่งออกข้อมูลเป็นไฟล์
  • บนอุปกรณ์เครื่องอื่น เลือกการตั้งค่า → นำเข้าบันทึกแล้วเปิดไฟล์นั้นเพื่อกู้คืนทุกอย่าง
  • ไฟล์สำรองที่ส่งออกจากเวอร์ชันเว็บรุ่นเก่าก็นำเข้าได้เช่นกัน
ฉันติดตั้งแอปด้วย Apple ID ฟรีแล้วเปิดไม่ได้

แอปที่ติดตั้งด้วย Apple ID ฟรีต้องรัน (ติดตั้งซ้ำ) ใหม่ทุก 7 วัน ข้อมูลจะยังอยู่เมื่อติดตั้งซ้ำ แต่แนะนำให้สำรองด้วยบันทึกข้อมูลก่อน หากมีบัญชีนักพัฒนาแบบเสียเงิน (99 ดอลลาร์ต่อปี) แอปจะใช้ได้นาน 1 ปี

ติดตั้งบน iPad อย่างไร
  • บน Mac เปิด FamilyCourt.xcodeproj ใน Xcode
  • ใน Signing & Capabilities เลือก Apple ID (Team) ของคุณเอง
  • เชื่อมต่อ iPad แล้วกด ▶ Run เพื่อติดตั้ง
  • ดูขั้นตอนทั้งหมดได้ใน README บน GitHub
ลบข้อมูลของฉันให้หมดได้อย่างไร

การลบแอปจะลบข้อมูลทั้งหมดที่เก็บในอุปกรณ์ ข้อมูลครอบครัวและการพิจารณาคดีไม่เคยออกจากอุปกรณ์ จึงไม่มีอะไรเหลืออยู่ที่อื่น หากต้องการให้ลบความคิดเห็นที่ส่งด้วยส่งความคิดเห็น ส่งอีเมลมาที่ leeo@kakao.com
