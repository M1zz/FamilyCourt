このアプリについて

😤

「ずるい！」と思ったとき

子どもが原告になって訴状を出せます。もやもやした気持ちを言葉にする民事裁判です。

🚨

家のルールを破ったとき

家のルールが破られたら、検察官が事件を提起します。裁判官は有罪・無罪・情状酌量から判断します。

🧑‍⚖️

みんなが公平な役割で

裁判官になれるのは、原告でも被告でもない人だけ。弁護人を選ぶ権利もみんなにあります。

📖

わが家の法律書

家族でルールを決めて書きとめ、裁判から判決、約束まで事件を最後まで見届けます。

遊び方

  1. まず家族で家の法律を決めて、法律書に書きます。
  2. 不公平なことがあれば民事事件、ルール違反があれば刑事事件を提起します。
  3. 原告・被告・裁判官・弁護人の役割を決めて、開廷します。
  4. それぞれの言い分を聞いたら、裁判官が判決を言い渡します。
  5. 判決をもとに約束を決め、守れたらチェックします。
🔒

子どもも安心

会員登録も広告も、追跡もありません。家族の情報、法律書、裁判の記録はお使いの端末の中だけに保存され、外部には送られません。開発者に届くのは、設定からご自身で送ったご意見と、個人を特定できない匿名の利用統計だけです。詳しくはプライバシーポリシーをご覧ください。
