요약 — 가족·재판 기록은 기기 밖으로 나가지 않습니다.
「억울해요」에는 회원가입, 로그인, 광고, 분석 도구가 없습니다. 가족·법전·재판·판결 등 모든 기록은 사용자의 기기 안에만 저장됩니다. 개발자에게 전달되는 정보는 사용자가 [피드백 보내기]로 직접 보낸 내용뿐입니다.

1. 수집하는 개인정보

본 앱은 앱을 사용하는 동안 이름, 이메일, 위치, 연락처, 사진, 기기 식별자 등의 개인정보를 자동으로 수집하지 않습니다. 계정을 만들거나 로그인할 필요도 없습니다. 사용 통계나 크래시 기록도 보내지 않습니다.

예외는 사용자가 설정의 [피드백 보내기]로 직접 보내는 의견입니다(아래 4항).

2. 데이터 저장 위치

사용자가 앱에서 입력한 정보(가족 구성원 이름, 우리 집 법 조문, 소송·재판·판결 기록 등)는 기기 내부의 앱 문서 폴더에 있는 familycourt.json 파일에만 저장됩니다.

  • 이 데이터는 사용자의 기기를 벗어나지 않습니다.
  • 당사를 포함한 어떤 외부 서버로도 전송되지 않으며, iCloud로 동기화되지도 않습니다.
  • 앱을 삭제하면 해당 데이터도 함께 삭제됩니다.

3. 데이터 백업과 이동

사용자는 앱의 [기록 저장] 기능으로 데이터를 파일로 내보내거나 다시 불러올 수 있습니다. 이 백업 파일은 사용자가 직접 관리하며, 저장·공유 위치는 전적으로 사용자가 선택합니다. 당사는 이 파일에 접근하지 않습니다.

4. 피드백 보내기 (사용자가 직접 보낼 때만)

설정의 [피드백 보내기], 또는 앱이 가끔 묻는 「억울해요를 즐겁게 쓰고 계신가요?」에서 [아쉬운 점이 있어요]를 골라 의견을 작성해 보내면, 아래 정보가 Apple의 iCloud(CloudKit) 공용 데이터베이스를 거쳐 개발자에게 전달됩니다. 보내려면 기기가 iCloud에 로그인되어 있어야 하며, 사용자가 보내기 버튼을 누르기 전에는 아무것도 전송되지 않습니다.

  • 의견의 종류와 사용자가 쓴 내용
  • 기기 정보: 앱 버전, 기기 모델, iOS 버전, 언어·지역 설정
  • 회신용 이름·이메일 — 사용자가 적었을 때만 (선택)

이 정보는 문의에 답하고 앱을 고치는 데만 쓰며, 다른 목적으로 쓰거나 제3자에게 넘기지 않습니다. 개발자가 답장을 남기면 앱이 보낸 의견의 번호로 그 답장만 불러와 보여 줍니다. 보낸 의견을 지우고 싶다면 아래 연락처로 요청해 주세요.

5. 제3자 제공 및 외부 서비스

본 앱은 광고 네트워크, 분석(애널리틱스) 도구, 소셜 로그인, 외부 SDK를 사용하지 않으며, 제3자에게 정보를 제공하지 않습니다. 피드백 보내기에 쓰이는 iCloud는 Apple이 운영하며, Apple의 개인정보 처리방침이 적용됩니다. 앱이 별점 평가를 요청할 때는 Apple의 기본 평가 창을 사용하며, 당사는 그 내용을 받지 않습니다. 피드백 보내기를 제외한 모든 기능은 인터넷 연결 없이 동작합니다.

6. 어린이 개인정보 보호

본 앱은 가족이 함께 사용하도록 설계되었으며 어린이가 사용하기에 안전합니다. 가족 구성원 이름 등 앱에 입력된 내용은 기기에만 남으며, 부모·보호자가 언제든지 앱 내에서 수정하거나 삭제할 수 있습니다. 피드백 보내기는 기기가 iCloud에 로그인되어 있고 사용자가 직접 보내기 버튼을 눌러야만 전송됩니다. 어린이가 의견을 보낼 때는 보호자가 함께 확인해 주시기 바랍니다.

7. 사용자의 권리

기기에 저장된 기록은 앱 내에서 언제든지 직접 수정하거나 삭제할 수 있고, 앱을 삭제하면 모두 제거됩니다. 보낸 의견의 열람·삭제를 원하시면 아래 연락처로 요청해 주세요.
