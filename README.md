# ⚖️ 땅땅! 우리집 법정 (Gavel Kids)

가족 역할극으로 아이에게 **법과 공정함**을 가르쳐주는 iOS 앱입니다. 아이폰·아이패드 모두 지원하며,
모든 기록(가족, 법전, 소송, 판결)은 앱 안에 자동 저장됩니다. (판사봉 소리 "땅땅"에서 따온 이름이에요.)

## 어떻게 움직이나요? (목표 중심 설계)

정해진 마스터(관리자)가 없습니다. 역할은 **사건마다** 소송을 접수하는 사람이 정합니다.

- **😤 억울한 일이 있어요 → 민사 소송**: 억울한 사람(아이도!)이 **원고**가 되어
  피고와 판사를 직접 골라 고소장을 접수하면 바로 소송이 시작됩니다.
- **🚨 우리 집 법을 어겼어요 → 형사 소송**: 법을 어긴 사람을 본 사람(주로 부모)이
  **검사**가 되어 피고인과 판사를 골라 기소합니다. 판결은 유죄/무죄/선처.
- 재판에 넘겨진 사람은 재판 시작 전에 자기를 도와줄 **변호인**을 고를 수 있습니다.
- 판사는 원고(검사)·피고(인)와 다른 사람만 고를 수 있어 공정함을 지킵니다.

앱은 기능별 메뉴가 아니라 **사건 중심**으로 움직입니다. 홈에서 사건을 접수하거나 목록에서
사건을 탭하면 그 사건의 전용 화면이 열리고, 그 안에서 진행 단계(접수 → 재판 → 판결 → 약속),
역할, 재판 진행, 판결문, 약속 체크까지 모두 처리합니다. 법전·가족·설정 탭은 보조 도구입니다.

## 설치 방법 (아이패드에 넣기)

1. **Mac에서 Xcode 열기** — Xcode 15 이상 권장 (App Store에서 무료 설치)
2. 이 폴더의 `FamilyCourt.xcodeproj` 파일을 더블클릭해서 엽니다.
3. 왼쪽 파일 목록 맨 위 **FamilyCourt(파란 아이콘)** 클릭 → **Signing & Capabilities** 탭:
   - **Team**: 본인의 Apple ID 계정을 선택하세요.
     (계정이 없으면 Xcode 메뉴 → Settings → Accounts에서 `+` 버튼으로 Apple ID 로그인)
   - **Bundle Identifier**: `com.family.familycourt`가 다른 사람과 겹치면 오류가 나요.
     `com.본인이름.familycourt` 처럼 살짝 바꿔 주세요.
4. 아이패드를 USB 케이블로 Mac에 연결하고, Xcode 상단 기기 선택에서 내 아이패드를 고릅니다.
   - 처음 연결하면 아이패드에서 "이 컴퓨터를 신뢰" 를 눌러 주세요.
   - 아이패드 설정 → 개인정보 보호 및 보안 → **개발자 모드**를 켜야 할 수 있어요.
5. **▶ 실행(Run)** 버튼을 누르면 앱이 아이패드에 설치됩니다!
6. 처음 실행 시 "신뢰하지 않는 개발자" 경고가 뜨면:
   아이패드 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → **신뢰**를 눌러 주세요.

> 💡 무료 Apple ID로 설치한 앱은 7일마다 다시 실행(재설치)해 줘야 합니다.
> 유료 개발자 계정($99/년)이면 1년간 유지되고 App Store 출시도 가능해요.
> 데이터는 재설치가 아닌 이상 유지되며, 홈 화면의 "기록 저장"으로 백업할 수 있습니다.

## 앱 내용 수정하기

앱은 100% SwiftUI 네이티브입니다. 재판 대본과 기본 법전 조문은 `Store.swift`와
`Models.swift`에, 화면은 각 View 파일에 있습니다. 수정 후 다시 Run 하면 반영됩니다.

## 구조

```
FamilyCourt/
├── FamilyCourt.xcodeproj      ← Xcode에서 여는 파일
└── FamilyCourt/
    ├── FamilyCourtApp.swift   ← 앱 진입점 (SwiftUI)
    ├── ContentView.swift      ← 탭 구성 (법원·법전·가족·설정)
    ├── Models.swift           ← 데이터 모델 (사건·법·가족·판결)
    ├── Store.swift            ← 상태 저장(JSON)·재판 대본
    ├── Sound.swift            ← 의사봉·타이머 소리 합성
    ├── HomeView.swift         ← 홈 액션 런처 + 소환/판례 목록
    ├── FilingView.swift       ← 소송 접수 (역할 지정)
    ├── CaseDetailView.swift   ← 사건 허브 (진행 단계·판결·약속)
    ├── TrialView.swift        ← 재판 진행 (대본·타이머·판결 선고)
    ├── SupportViews.swift     ← 법전·가족·설정·법원 공부
    └── Assets.xcassets        ← 앱 아이콘 (⚖️ 저울)
```

> 데이터는 앱 문서 폴더의 `familycourt.json`에 저장되며, 예전 웹뷰 버전에서
> 내보낸 백업 파일도 [설정 → 기록 불러오기]로 그대로 읽을 수 있습니다.
